Control con IA

Controla el vehículo con tu voz, tus manos o inclinando el celular.

🎤 Voz: "avanza", "avanza 3 segundos", "retrocede", "gira a la derecha", "sube el brazo", "motor izquierdo", "enciende la luz", "activa el turbo", "toca el claxon", "inicia la demo de excavación", "cancela la demo", "alto".

✋ Gestos: ☝ apunta con el índice arriba/abajo/a los lados para avanzar, retroceder o girar · ✋ palma o ✊ puño = detener · 👍/👎 subir/bajar brazo · ✌ luz · 🤟 sonido.

📱 Giroscopio: en 🚜 Conducir, inclina el celular adelante/atrás para avanzar/retroceder y a los lados para girar. En 🦾 Brazo, inclina hacia ti para subir el brazo, adelante para bajarlo y a los lados para mover el motor izquierdo o derecho. En ✨ Accesorios, inclina adelante para el turbo, a la izquierda para la luz y a la derecha para el sonido (regresa al centro entre uno y otro). Regresa a la posición inicial para detener.
